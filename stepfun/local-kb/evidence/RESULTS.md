# 实测结果与复现边界

最终测量文件：`benchmark-1793279895966.json`。2026-10-29，Apple M5、32 GB 内存、macOS 26.6，Edge 156.0.0.0；Node 24.22.1、Transformers.js 3.8.1、seekdb-js 1.4.0，原生 seekdb 1.4.0.0。数据库为本机独立嵌入式实例，384 维 cosine HNSW、IK 全文索引，数据库内 RRF。

固定自写语料 16 篇、16 条带单个相关文档标签的查询，见 dataset.js；各配置完整导入 3 次，查询集重复 3 次，保留全部 48 次查询与每次导入记录，表中耗时为中位数。Recall@3 为唯一相关文档是否在前三，nDCG@3 以相关文档排名计算；因此本集不是大规模公开基准。

| 配置 | 16 篇向量化 ms | 完整导入 ms | seekdb 检索 ms | 端到端查询 ms | Recall@3 / nDCG@3 |
|---|---:|---:|---:|---:|---:|
| fp32 / wasm / 每批写 1 | 254.4 | 6628.6 | 2.79 | 10.1 | 0.9375 / 0.8683 |
| q8 / wasm / 每批写 1 | 247.7 | 6617.1 | 3.09 | 12.5 | 0.9375 / 0.9144 |
| q8 / wasm / 每批写 100 | 268.4 | 526.5 | 3.43 | 12.2 | 0.9375 / 0.9144 |
| fp16 / webgpu / 每批写 100 | 82.8 | 557.7 | 3.47 | 11.7 | 0.9375 / 0.8683 |

控制变量：第二和第三行只有数据库每批写入量及相应刷新频率不同，INT8 WASM、向量批大小 1 不变。导入包括浏览器向量化、内容哈希、请求、upsert 和索引刷新；查询端到端包括查询向量化、HTTP 请求与数据库返回，随后页面直接展示结果。GPU 与 WASM 的精度不同，不能把其差异解释成单独的 GPU 加速效果。

逐条写入重复等待 16 次索引刷新，批量写入等待 1 次；INT8 WASM 完整导入从 6617.1 ms 降到 526.5 ms，约 12.57 倍，质量保持一致。小语料向量化采用 batch=1；诊断实验中 batch=8 没有稳定收益，因此不采用。模型仅加载一次、后续查询复用同一 pipeline，计算放在 Worker 中，界面不被推理阻塞。

模型权重固定 revision `751bff37182d3f1213fa05d7196b954e230abad9`。ONNX 权重 FP32 90,387,606 字节、INT8 22,972,370 字节、FP16 45,297,825 字节，权重压缩比为 3.9346 和 1.9954。统一口径再加同一份 tokenizer/config 共 944,310 字节后，模型包总体积 FP32 91,331,916、INT8 23,916,680、FP16 46,242,135 字节，总体压缩比为 3.8188 和 1.9751；实测大小与 SHA-256 见 model-files.json。

本轮每种配置的首次模型加载（含本地获取和初始化）为 FP32 WASM 248.5 ms、INT8 WASM 46.9 ms / 41.7 ms、FP16 WebGPU 73.4 ms；随后先执行一次 warmup，再进行统计。已下载模型由本地静态服务和浏览器 Cache API 加载，以上不代表公网首次下载耗时。公开站点下载速度随网络变化，下载工具独立于浏览器推理；未将下载站速度计入推理性能。原始资源计时确认运行库来自 `127.0.0.1:5173/ort/`，不再访问 CDN。

最终 WASM 为手动强制选择的真实 WASM 执行，WebGPU 为真实适配器检测后选择 FP16；本机具备 WebGPU，未声称在另一台无 WebGPU 设备上复测。自动降级代码在适配器缺失、缺少 shader-f16 或 GPU 初始化失败时转 WASM；页面显示实际后端。

`benchmark-1793278400695.json` 为诊断记录：INT8 WebGPU 的 Recall@3 为 0.6875，batch=8 也未见提速。最终应用已改用 FP16 WebGPU 并重测，Recall@3 回到 0.9375，与 FP32 相同。保留该记录便于核对技术选择，不将其当作最终配置结果。

真实数据库回归见 api-tests.tap。已确认重复导入不增加片段，增量写入刷新后立即可检索，切换新集合不返回旧集合数据；数据库重启后 personal 集合仍有 16 篇。服务在接收请求前先初始化原生数据库，避免首次并发初始化竞争。合成向量只用于数据层回归；上述质量和性能全部来自浏览器模型实际计算。

模型以英文为主，中文语义能力和大规模吞吐不在本次证据覆盖范围。server 模式配置可用但未另做实测。正式得分以比赛平台评审为准。
